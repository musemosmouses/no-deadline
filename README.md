## The entry

> The deadline never texted back, so I assumed we were on a break.

64 characters, one line. The deadline is treated like a partner who ghosted — no text back, so the speaker assumed they were on a break. The excuse lands on the last phrase, in the voice of someone cornered and bluffing with a straight face.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
